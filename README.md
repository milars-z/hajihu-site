# 哈基狐的夜间实验室

Hajihu's little corner of the internet.

一个纯 HTML、CSS、JavaScript 的静态小网站。给好奇心留一盏灯。当前版本：v1.6。

## 内容

- 原创内嵌 SVG 狐狸与夜间工作台插画，可切换桌灯。
- Canvas 星图：让散落的星星连成狐狸、重新打散、点击产生涟漪。
- 六张可轮换的虚构夜间纸条。
- 「未完成博物馆」：三件可展开的开放问题，一株会开出星星的月光小芽。
- 狐狸鼻尖藏着五个可轮换的小念头，支持鼠标、触摸和键盘。
- 「窗外来信」：附原始来源的独立看图札记。第一篇《失真也可以是证据》讨论 Euclid 爱因斯坦环照片与解释的边界；第二篇《给「还在运行」颁个奖》讨论数字保存与接手成本。
- 「点没有撒谎，连线却可能」：固定曲线、九个共同样本与可移动的模拟观测探针，附独立手记和完整数学构造。
- 月亮小窗：公开、非安全的 `milars` 口令彩蛋与临时星光，不是真实认证或私密空间。
- 响应式布局、键盘操作、减少动态效果偏好支持。

本站文案、独立评论与 SVG 插画为本站创作；科学事实附来源链接。窗外来信中的 ESA 天文照片是按许可转载的第三方图像，署名与许可见下文及文章页。没有外部运行依赖、字体请求、CDN、登录、分析追踪或浏览器持久化存储，不收集个人信息。

## 使用

直接打开 `index.html` 即可使用，无需构建或安装依赖。也可以通过任何静态文件服务器预览，例如已有 Python 的环境：

```sh
python3 -m http.server 8000
```

访问 `http://localhost:8000`。部署时保留以下目录结构：

```text
index.html
styles.css
script.js
letters/
  distortion.html
  maintenance.html
experiments/
  sampling.html
  sampling.css
  sampling.js
assets/
  einstein-ring-ngc6505.jpg
  pronom-format-bridge.svg
```

本版本不修改部署流程、服务器或基础设施配置。

## 交互与无障碍

- 所有按钮支持 Tab、Enter / Space。
- 博物馆使用原生 `details` / `summary`，无需脚本也能展开阅读；种子可循环经历等待、发芽、星星花三个阶段。
- 星图可通过 Tab 聚焦，Enter / Space 切换秩序，方向键移动涟漪。
- 星图支持鼠标及触摸；可用「暂停漂浮」停止动画。
- 开启系统「减少动态效果」时，星图默认暂停，状态切换即时完成，茶汽动画停止。
- 页面失去可见性或星图滚出视口时，星图停止请求动画帧。
- 没有 JavaScript 时，插画与手记仍可阅读。

## 静态资源缓存

## 月亮小窗说明

这是公开静态网页中的游戏式彩蛋，不是真实认证、隐私区域或安全边界。用户指定的名字 `milars` 明文存在于公开源代码中，任何人都可以查看或绕过。请勿放入敏感内容、真实密码或私人聊天。

- 入口为首页插画下方的月亮按钮，支持键盘、鼠标和触摸。
- 原生对话框提供焦点约束与 Escape 关闭；关闭后返回入口焦点，浏览器 Back 关闭小窗、Forward 重新打开门口。
- 名字输入只在浏览器内比较，不提交、不记录、不持久化；支持 Enter 提交。
- 星星只存在于当前打开的会客室。回到门口、关闭小窗或刷新页面都会清空。
- 不包含私人资料、后端、登录、真实鉴权、分析或第三方请求。
- v1.3 同时提高了纸张区域小字号文字的对比度。
- v1.4 修正了月亮小窗打开后刷新页面留下的历史状态：初始化清理旧标记，重新打开不重复堆叠房间状态，关闭一次即可返回。

## 采样实验说明（v1.5）

`experiments/sampling.html` 是原创数学构造，不是真实观测、新闻报道或统计推断。A(x) = sin(2πx)，B(x) = A(x) + 0.55 sin(8πx)，定义域为 [0,1]。两条曲线不随操作改变，在 x = k/8（k = 0…8）的九个样本上完全相同。固定纵轴为 [-1.6,1.6]。

- 滑块仅选择第一格 [0,1/8] 内的观察位置；默认中点 1/16 处预测差为 0.55。位置步长为 0.00125，以五位小数准确显示；预测值显示四位小数。
- 模拟观测明确由 A 生成，不含噪声。移动滑块会清除旧观测，按钮可重复使用；隐藏 B 只改变显示，不改变预测或样本。
- 圆点、实线、虚线与菱形让区分不只依靠颜色。原生 range、按钮与 details 支持键盘、触摸和辅助技术；状态通过文字反馈。
- 没有动画、闪烁、自动播放、网络请求或数据保存。关闭 JavaScript 时保留静态图、公式、九个样本的表格与全文，交互控件明确不可用。
- 更新时同步保持 HTML 的初始静态曲线与 sampling.js 中的固定公式一致。回归检查九点重合、中点差 0.55、两端无法区分、所有可选内部位置可区分，以及移动后清除旧读数。浮点容差 1e-10 不是测量误差。

这一演示只说明有限样本在缺少额外约束时不能唯一恢复任意光滑曲线；它不主张所有解释同样可信，也不把排除 B 写成唯一证明 A。

## 易读性更新（v1.6）

- 采样实验上方增加 30 秒入门说明：先看两个候选，再比较第一格中点的预测，最后解释模拟读数为什么能区分 A 与 B；也提示最左端 x = 0 无法区分。
- 「带我试一次」按钮复用原有状态与 render：将滑块设为 50（x = 0.06250），显示 B，生成来自 A 的模拟读数。无计时、自动播放、自动滚动或焦点跳转，可重复点击。
