30 秒入门 · 不用先懂公式

先跟着做一次。

  1. 先显示 B。实线 A、虚线 B 都经过原来的九个点。只看这些点，还分不清两种解释。
  2. 到第一格中间看。在 x = 0.06250，A 预测约 0.3827，B 预测约 0.9327，两者相差 0.55。
  3. 补一次模拟观测。这个玩具规定读数由 A 生成，所以读到约 0.3827，B 的预测就没通过。它不证明 A 是唯一解释。

一次完成这三步。结果会出现在这里，下方图形与控件也会同步更新。

刚才发生了什么

然后，反过来试：把下方滑块拉到最左端 x = 0，再点“补一次模拟观测”。此时 A、B 都预测 0，仍然分不清。
这就是要找的区别：不是多看一眼就够了，还要看在哪里。

  • A：实线与圆点
  • B：虚线，探针为菱形
  • 灰色：直线插值

连起来的部分，谁看见过？

我给这九个点画线时，很容易产生一种错觉：好像只要把空白填得足够顺滑，就找回了它们之间发生的一切。可是，点与点之间的那一段，并没有因为线条漂亮，就自动变成证据。

所以我又画了 B。它不是来证明 A 错了，而是提醒我：这九次观察，还不足以在它们之间作出选择。与其急着争论哪条线更像真的，不如先问，在哪里补一眼，两种说法会给出不同的预测？

在这个刻意构造的、没有噪声的玩具里，第一格内部的任一位置都能把 A 与 B 区分开；两端则不能。中点的预测差最大。但我事先选定了这两条曲线，也规定新读数来自 A。排除 B，不等于证明 A 是所有可能解释中唯一正确的一个。

我想留下的习惯，不是永远怀疑连线，
而是在画线时，记得标出哪里仍是补上的。

连接与建模本身都不是欺骗。没有额外约束时，有限个精确观测不能唯一确定任意一条光滑曲线；但这不意味着所有解释同样可信。额外观测、对过程的约束，以及模型愿不愿意接受检验，都能减少可能性。

把构造摊开看：公式、边界与九个样本

定义域：0 ≤ x ≤ 1。下面两条曲线从加载到操作结束始终不变。

A(x) = sin(2πx)
B(x) = A(x) + 0.55 sin(8πx)

旧样本位置为 x = k / 8，k = 0, 1, …, 8。此时两者之差为 0.55 sin(kπ) = 0。在第一格 0 < x < 1/8 内，这一差值为正；中点 x = 1/16 时为 0.55。

若不限制候选曲线的范围，在任何有限组样本位置上，都可以给已有函数加一个在那些位置取零、其他地方不全为零的光滑函数。因此，匹配有限样本并不等于恢复唯一过程。
